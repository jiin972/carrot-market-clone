# 🥕 Carrot Market Reloaded

### 🛠 Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Library**: React 19
- **Styling**: Tailwind CSS v4
- **Database**: Prisma ORM & SQLite
- **Validation**: Zod v4 & validator.js
- **Authentication**: bcrypt, iron-session,
- **Real-time Communication**: Supabase Realtime

### 🎯 Key Features & Technical Points

- **Next.js 16 Server Actions**: `useActionState`를 활용한 비동기 상태 관리 및 폼 처리.
- **Type-Safe Validation**: Zod를 이용한 서버/클라이언트 통합 유효성 검사.
- **ORM Integration**: Prisma를 활용하여 SQLite 데이터베이스와 타입 안전한 상호작용.
- **Modern UI**: Tailwind CSS v4를 이용한 반응형 및 효율적인 디자인 구현.

### 📖 Project Insight

이 프로젝트는 당근마켓의 핵심 기능을 재구현하며 실무적인 Next.js 활용 능력을 키우는 것을 목표로 합니다. 특히 데이터 유효성 검사 과정에서 발생하는 복잡한 에러 타입을 `ZodFlattenedError` 등을 활용해 체계적으로 관리하는 데 집중하고 있습니다.
